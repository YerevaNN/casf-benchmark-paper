\section*{Selection of the core and ref evaluation panels}

The core panel contains 94 ChEMBL parent compounds and the ref panel contains
1,042. They share 17 parent compounds but no crystal-complex identifiers. All 285
core inputs parsed successfully. The final ref panel contains one crystal per
canonical heavy-atom isomeric SMILES identity, giving 1,044 complexes.

Table~\ref{tab:selection-counts} accounts for the input structures in the recorded
matching runs. Exclusions are sequential and mutually exclusive; a structure rejected
at an earlier stage is not counted again. These are panel-selection counts, before
generation or PoseBusters filtering of conformer ensembles.

The matching procedure reads the supplied MOL2 structures with RDKit and generates
canonical heavy-atom isomeric SMILES. ChEMBL3D index matches must also have a readable
topology record with matching stereochemistry. Identity checks use canonical isomeric
SMILES and the stereochemical layers of InChI, assigning stereochemistry from the
topology coordinates. Other stereoisomers sharing a ChEMBL parent identifier are not
included. Torsional eligibility is checked on the prepared matching topology. The
stored conformer count is restricted to the selected stereoisomer.

Within the 1,236 matched ref complexes, 114 ligand identities occur in more than one
crystal and account for 306 entries. Selecting one crystal for each of these identities
removes 192 entries. The frozen selection ranks candidates by the SHA-256 digest of a
fixed seed, the canonical heavy-atom isomeric SMILES, and the crystal identifier, with
the crystal identifier breaking ties. The seed is
\texttt{casf-ref-dedup-v1-20261030}. No generated structures or matching scores enter
this selection. The complete candidate list, selected crystal identifiers, and ranking
metadata are retained in the selection manifest.
