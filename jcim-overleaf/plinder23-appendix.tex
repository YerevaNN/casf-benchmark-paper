\section*{Selection and composition of the PLINDER-22 panel}

The evaluated panel derives from an exploratory, manually curated selection from PLINDER
release \textbf{2024-06/v2}, rather than an official PLINDER split. Selection began with the
release file \texttt{fingerprints/ligands\_per\_system.parquet}, grouped by its complete
\texttt{inchikeys} value to retain stereoisomers as separate identities. For each identity,
we counted distinct PDB identifiers, distinct system identifiers, and table rows as
ligand instances. The starting collection contained \textbf{51,280 identities}; the physicochemical
requirements in Table~S2 retained \textbf{25,392 (49.5\%)}.

\input{tables/plinder23-screen}

Surviving identities were ranked by descending number of distinct PDB entries, with system
count as the secondary ordering. PDB count takes priority because one multimeric
structure can contribute many systems. Manual review selected recognizable drugs and
medicinal-chemistry-like protein ligands, excluding common crystallization additives,
metabolites, cofactors, and other compounds outside the intended panel. These were
judgment-based categories rather than executable exclusion rules. Of 23 shortlisted
molecules, bortezomib was excluded because of covalent annotations, yielding the
22-molecule evaluation panel.

The panel is not a random sample or simply the most frequent PLINDER ligands. Exact
reproduction uses the archived \texttt{druglike\_curated\_shortlist.tsv}, which records
the shortlisted identities, SMILES, descriptors, and selection frequencies. The
evaluated identities are listed in Table S4. Training exclusions use all 23
shortlisted identities, including bortezomib.

Reference structures are deduplicated at 0.05~\AA{} symmetry-aware RMSD and aligned
using a fixed anchor atom triplet per molecule. Coordinate-based stereochemical
inspection excludes two inverted chloramphenicol records from PDB 2uxp and one
staurosporine epimer from PDB 2oic. The panel contains \textbf{1,067 references},
with \textbf{8--117 per molecule} and a median of \textbf{40}.

The retained references span \textbf{552 distinct PDB entries} and \textbf{1,045 PLINDER systems}.
A system can contain multiple ligand instances, so its identifier is not a unique conformer
key. Each record is identified by its CCD code and source conformer index. Duplicate-cluster
membership accounts for 2,258 source records after stereochemical exclusions, but each
retained representative receives equal weight within its molecule. Pleconaril illustrates the
effect of deduplication: 716 source records reduce to eight representatives. Reference counts
are not counts of distinct protein targets or biologically distinct conformational states.

The companion \texttt{plinder22-molecules.csv} records molecular identities, descriptors,
selection frequencies, and evaluated reference counts. Tables~S3--S4 describe the
evaluation panel.
Source hashes and the per-record reference manifest are archived in \texttt{plinder22-data/}.
